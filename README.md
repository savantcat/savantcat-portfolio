## 🚀 作品

### 1. 🏛️ [savantcat-answers-mcp](https://gitee.com/savantcat/mcp-savantcat) — 把国标变成 Agent 能调用的工具

> 中国 AI 客服国标 **GB/T 47746—2026**（2026-09-01 已实施）的条款级问答，封装成 MCP Server。

- ✅ **公网在线**，匿名只读，**不需要 API Key**
- ✅ 5 个工具：合规问答检索 / 自查清单 / 标准元信息 / 条款原文 / 要点
- ✅ 答案全部标注**条款出处**，可溯源
- ✅ 已被 **MCP 官方 Registry 收录**（`cn.savantcat/answers`）

**适合谁**：正在用 AI 客服、要过合规检查的企业；想让自己的 Agent 直接回答「国标要求什么」的开发者。

```bash
# 任何支持 MCP 的客户端
claude mcp add --transport http savantcat-answers https://savantcat.cn/mcp
```

### 2. ✍️ [content-creator-skills](https://gitee.com/savantcat/content-creator-skills) — 专治内容创作者最痛的三件事

> **写不完 · 像 AI 写的 · 没东西可写。**

| 技能 | 解决什么 |
|:---|:---|
| 一稿五发 | 一篇主稿 → 公众号/知乎/CSDN/小红书/百家号 各自适配版 |
| 去 AI 味 | 干掉"首先其次最后""总而言之"这类机器腔 |
| 旧文变选题 | 从历史文章里挖出还能再写一遍的角度 |

纯提示词，**零依赖**，丢进任何支持 `SKILL.md` 的 Agent（Claude Code / Hermes Agent / Cursor / Cline）就能用。

**适合谁**：一个人管 3 个以上平台的内容创作者。

### 3. 🌙 [memory-dream-engine](https://gitee.com/savantcat/memory-dream-engine) — 让 AI 拥有会衰减、会发芽的长期记忆

> 你的 AI 聊完就忘，不是它笨 —— 是它**从来不做梦**。

五阶段流水线：**采集 → 评分 → 写入 → 优化 → 发芽**，每 3 小时自动跑一轮。
把「重复事实去重、陈旧记忆衰减、碎片信息碰撞出新规律」做成可运行的代码。

- ✅ 仿人脑三阶段：浅睡扫描 / 深睡评分 / REM 联想
- ✅ **零 LLM 成本**提取（不烧 token 也能提炼事实）
- ✅ 艾宾浩斯遗忘曲线做强度衰减
- ✅ 纯标准库，~800 行 Python，**8/8 单元测试通过**

**适合谁**：想让 AI 真正记住自己、而不是每次重新解释一遍的人。

### 4. 🔀 [content-router](https://gitee.com/savantcat/content-router) — 一份素材进去，多种成品出来

> 写一次、改四次，是多平台创作者最耗命的地方。内容路由器把**「这篇该做成什么」变成一道可计算的问题**。

**11 维内容画像 → 智能推荐 8 种输出形态 → 一键调度**

- ✅ 不是模板填空：先给内容做体检，再基于结果匹配形态
- ✅ 永远给多个候选 + 匹配理由，决定权交回给人
- ✅ 单文件引擎，纯标准库，`python engine.py analyze 你的文章.md` 直接出报告

**适合谁**：手上素材多、但总把力气花在"错的形态"上的人。

## 🧭 我为什么坚持「零依赖」

不是我讨厌库，是**依赖会腐烂**。

一个 2024 年写的项目，三年后 `pip install` 往往先报三个错。纯标准库的代码不会 ——
它今天能跑，五年后大概率还能跑。**你 clone 下来跑不通的开源项目，等于不存在。**

所以这里的每个作品都尽量做到：没有虚拟环境、没有版本地狱、没有"先按文档装一遍再说"。
